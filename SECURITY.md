# Security policy

## Supported versions

Security fixes are applied to the latest `main` branch and the latest tagged
release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the
maintainer privately with the affected component, reproduction steps, impact,
and any suggested mitigation. You should receive an acknowledgement within
seven days.

Do not include credentials, tokens, personal data, or production URLs in a
report. Once a fix is available, the maintainer will coordinate disclosure and
credit the reporter when requested.
