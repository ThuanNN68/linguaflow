# LinguaFlow brand assets

LinguaFlow uses a blue conversation symbol as its primary identity. The speech
bubble represents communication across languages, while the yellow accent
suggests activity and intelligent assistance.

## `brand-mark.svg`

The compact symbol without text. Use it for navigation, application avatars,
favicons, shortcuts, and other small surfaces.

## `brand-wordmark.svg`

The standalone LinguaFlow name. Use it where the product name must be prominent
but the complete lockup would be too large.

## `brand-lockup.svg`

The complete mark and wordmark. Use it on authentication screens, welcome pages,
documentation, and other first-contact surfaces.

## Usage rules

- Preserve aspect ratio, colors, and clear space.
- Use the same assets in light and dark themes.
- Do not add effects, borders, shadows, or unapproved colors.
- Prefer the mark for compact areas, the wordmark for name-focused areas, and
  the lockup for introductory surfaces.

PNG files under `source/` are retained source assets. The application uses the
three SVG files in this directory.
